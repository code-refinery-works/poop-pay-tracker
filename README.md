# PoopPay (プープ・ペイ) 〜個室から生み出す不労所得〜 🚽💸

> 「個室の鍵を閉めた瞬間、労働は富へと変わる。」

現代のストレス社会をサバイブするすべてのビジネスパーソンに捧ぐ、**トイレ滞在時間最適化・経済的価値可視化Webアプリケーション**です。
就業時間中のトイレ籠城タイムを「生産的デトックス」へと昇華させ、1秒ごとに会社から獲得している給与をリアルタイムにチャリンと可視化します。

---

## ✨ 主要機能 (Features)

- 💰 **秒給リアルタイムカウンター**: 設定した年収・時給から秒給を即座に算出し、札束が舞い散るアニメーションと共に不労所得をカウントアップ。
- 🎯 **マイルストーン達成演出**: 「缶コーヒー獲得(100円)」「実質、会社があなたの便を買いました(1,000円)」など、モチベーションを高める通知が次々に降臨。
- 🚨 **パニックボタン（上司接近カモフラージュ）**: ノックや足音を察知したらワンタップ。即座に「高度な関数の入ったExcelスプレッドシート画面」へ偽装。
- 🎵 **サウンドマスキング**: 流水音を超えた「ウォール街の喧騒」「深夜オフィスのタイピング音」でデキる社員を演出。
- 🛡️ **安心のプライバシー配慮**: 完全匿名性、位置情報完全破棄、退室時の履歴隠滅サニタイズ。

---

## 🛠️ 技術スタック

- **Frontend**: Next.js / React / Tailwind CSS / Lucide Icons / Canvas Confetti
- **Audio**: Web Audio API (SE & サウンドマスキング)
- **Theme**: ゴージャスゴールド & 便器オフホワイト（ダークモード標準対応）
